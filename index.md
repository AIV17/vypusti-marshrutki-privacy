# Политика конфиденциальности игры «Выпусти маршрутки»


26 ноября 2026 года


Издатель игры в RuStore — Almoren Games. Для вопросов об обработке данных и запросов на их удаление используйте адрес [nardiasupport@gmail.com](mailto:nardiasupport@gmail.com).


## Игровые данные


Регистрация для игры не нужна. Прогресс, монеты, покупки за игровые монеты, выбранные темы и машины, статистика заданий и настройки хранятся на устройстве. Эти сведения нужны для восстановления игровой сессии и сохраняются до удаления приложения либо очистки его данных в настройках Android. Для прохождения уровней подключение к интернету не требуется.


## Реклама


Для показа рекламы игра запрашивает объявления через Yandex Mobile Ads SDK. В запросах могут обрабатываться технические сведения о приложении, устройстве, версии Android и сетевом соединении, включая IP-адрес. Рекламный сервис может регистрировать показ, закрытие объявления и выполнение условия для награды. Эти данные используются для доставки рекламы, проверки выполнения условия награды, учёта показов и защиты от злоупотреблений.


В игре включён режим возрастных ограничений SDK, отключено отслеживание местоположения и исключено разрешение Android на доступ к рекламному идентификатору Google. Игра отключает персонализацию рекламы средствами SDK.


Яндекс обрабатывает данные, необходимые для работы его рекламного сервиса. Порядок обработки, применяемые сроки хранения и контакты Яндекса указаны в [политике конфиденциальности Яндекса](https://yandex.ru/legal/confidential/).


## Управление данными


Сведения об использовании рекламы и ссылка на эту политику доступны в настройках игры. Уровни доступны офлайн. Просмотр за монеты или подсказку запускается только по выбору игрока.


Чтобы удалить игровой прогресс и настройки, очистите данные игры в настройках Android. Чтобы уточнить, какие данные обрабатываются, либо запросить их удаление, напишите на адрес издателя выше. Для исполнения запроса может потребоваться дополнительная информация. Переписка по запросу хранится столько, сколько необходимо для ответа и выполнения применимых обязанностей. Запросы о данных, полученных рекламным сервисом, также можно направить Яндексу по контактам из его политики.
